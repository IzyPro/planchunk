## Planning with planchunk

Plans live in `plans/<slug>/` (format: `~/.planchunk/core/FORMAT.md`).
When the user asks to explore, create, convert, continue, verify, sync, split, archive, check the status of a plan, explain a point in depth, or run a whole plan, follow `~/.planchunk/skills/pc-<name>/SKILL.md`.
Names: `explore`, `create`, `convert`, `next`, `verify`, `sync`, `split`, `archive`, `status`, `expatiate`, `orchestrate`.
Work on one chunk per session. Run `pc-sync` at the end. Token efficiency mode is on by default (`~/.planchunk/core/EFFICIENCY.md`); the user can say "efficiency off".
